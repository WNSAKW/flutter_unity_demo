- **Demo**: Flutter to Unity
- **version**: 2026.03.18 Wed.

#### 安裝插件
1. flutter_unity：把"[Editor](https://github.com/WNSAKW/flutter_unity_demo/blob/main/flutter_unity/Editor)"資料夾下載並放到unity專案的Asset資料夾中
   - unity專案路徑：須在flutter專案中新增unity資料夾，並將unity專案放在該資料夾中
   - 如圖：[flutter_unity_demo.png](https://github.com/WNSAKW/flutter_unity_demo/blob/main/flutter_unity/flutter_unity_demo.png)
   - reference：
     - [pub.dev: flutter_unity_widget 2022.2.1](https://pub.dev/packages/flutter_unity_widget)
     - [Github: flutter_unity_widget](https://github.com/juicycleff/flutter-unity-view-widget/tree/master)
     - [Github: flutter_unity_youtube](https://github.com/cmrnrbs/flutter_unity_youtube/tree/master)
     - [Youtube: Run Unity Projects with Flutter](https://www.youtube.com/watch?v=1HHIER5dLUY)
2. Addressables 插件：在 Package Manager 中下載
   - 如圖：[unity_Addressables.png](https://github.com/WNSAKW/flutter_unity_demo/blob/main/flutter_unity/unity_Addressables.png)
   - 一個場景 = 一個關卡（用來給flutter呼叫不同的 Addressables）
   - reference：[Unity Addressables 資源管理](https://blog.csdn.net/linxinfa/article/details/122390621)
